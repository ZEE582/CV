# سجل تغييرات الحسابات والشركات

في `/admin/contacts` و`/admin/team` يظهر زر **سجل التغييرات** لكل حساب، وفي `/admin/companies` يظهر للشركة. العرض خاص بالمدير فقط. لا يحتاج فتح السجل إلى حفظ أو تعديل أي بيانات، ويمكن إغلاقه أو تحديثه وإعادة المحاولة عند الفشل.

## العمليات المشمولة

- تغيير حالة الحساب أو صلاحيته من مسارات الإدارة، بما فيها مسارات التوافق للإيقاف والتفعيل وتغيير الدور.
- إنشاء الشركة وتعديل حقولها بواسطة المدير أو مالكها، وتوثيقها وإيقافها.
- ربط حساب شركة جديد بشركة موجودة من مسار إنشاء حساب الشركة.

السجل لا يشمل كلمات المرور وتسجيل الدخول وتعديلات الملف الشخصي أو قرارات التوظيف أو الرسائل أو التقويم أو الاستيراد والكتابات المباشرة إلى MongoDB. إنشاء حساب شركة دون ربطه بشركة لا يضيف حدثًا لهذا السجل. لا توجد تعبئة تاريخية للتعديلات السابقة أو ادعاء بأن سجلًا فارغًا يعني عدم حصول تعديل سابق.

## ما يُحفظ وكيف

يُحفظ وقت العملية ومعرف المنفّذ ودوره حينها ورقم طلب مولّد من الخادم ونوع العملية ونسخة السجل وأسماء الحقول المتأثرة. تُحفظ حالة الحساب ودوره قبل التغيير وبعده، أو حالة الشركة وتوثيقها ووجود حساب إدارة مرتبط. لا تُحفظ قيم أسماء الشركات والبريد والوصف وروابطها أو كلمات المرور والرموز وعناوين IP وبيانات السير. اسم المنفّذ المعروض يُقرأ من حسابه الحالي؛ يظهر «اسم غير متاح» عند غيابه، مع بقاء معرفه للتمييز بين الأسماء المتشابهة.

التغيير والحدث والعداد في وثيقة MongoDB نفسها: تحديث ذري واحد مشروط بالنسخة يكتبها معًا. لا توجد كتابة ثانية إلى جدول منفصل قد تفشل بعد نجاح التعديل. عند تعارض تحديثين يُحفظ الفائز وحدثه فقط. يرفض مسار الشركة نسخة متوقعة تختلف عن النسخة التي قرأها قبل بناء حالة «قبل الحفظ»، ثم يعيد التحقق منها في شرط الكتابة. عمليات حفظ الشركة التي لا تغيّر القيم لكنها تقدّم النسخة تُعرض بوضوح «حفظ دون تغيير في قيم الحقول»؛ الحساب يرفض الحفظ بلا تغيير كما كان سابقًا. في إنشاء حساب الشركة، يحفظ الربط وحدثه ذريًا داخل الشركة؛ إنشاء وثيقة المستخدم ثم الربط ليسا معاملة واحدة، وتبقى آلية التعويض السابقة عند فشل الربط.

تحفظ كل وثيقة آخر100عملية فقط، مع عداد إجمالي للعمليات المسجلة منذ تفعيل الميزة. يظهر التنبيه عند اختصار الأقدم. ترتيب العرض حسب النسخة من الأحدث إلى الأقدم، لا اعتمادًا على ساعة المتصفح. قد توجد فجوات في النسخ بسبب عمليات سابقة أو غير مشمولة. هذا سجل تشغيل محدود، وليس سجلًا قانونيًا دائمًا أو مقاومًا لتعديل مدير قاعدة البيانات. حذف وثيقة الهدف مباشرةً يحذف سجلها معها؛ مسارات الإيقاف المعتادة تحتفظ بها وبالسجل.

حقلا `change_history` و`change_history_total` مخفيان افتراضيًا في Mongoose ومحذوفان من تحويلات المستخدم والشركة المعتادة. المسار المخصص يختار حقولهما صراحةً ويعيد DTO محدودًا. لا يُضاف تاريخ الإدارة إلى استجابة الدخول أو الملف الشخصي أو قوائم الشركات العامة أو بيانات مالك الشركة. يفحص عميل الواجهة الهدف والنوع والعدادات والحد وترتيب النسخ والحقول والحالات والهوية، ويرفض الرد غير الصالح بدل عرض سجل مضلل.

## API

```text
GET /api/admin/users/:id/history
GET /api/admin/companies/:id/history
```

Bearer مدير مفعّل مطلوب. الرد no-store؛ غير المسجل401، الحساب المسجل دون صلاحية403، المعرّف غير الصالح400، والهدف غير الموجود404. لا يوجد مسار عام لقراءة السجل أو مسار لإضافة حدث أو تعديله أو حذفه. يبقى رمز الجلسة في Authorization وليسURL، ولا يرسل عميل السجل كوكيز. تغيير الجلسة أو إلغاء الطلب يمنع اعتماد الرد، وإغلاق النافذة يلغي القراءة. تُمسح البيانات المعروضة عند فتح جديد أو التحديث، ولا توجد إعادة محاولة تلقائية أو حفظ محلي للسجل.

الرد يحتوي `kind,target_id,recorded_total,retained_limit:100,older_history_available:false,events`. الحقل الأخير لا يعني اكتمال التاريخ؛ الأقدم قبل تفعيل الميزة أو قبل آخر100عملية غير متاح. يتضمن الحدث actor_id وactor_name الحالي أوnull وactor_role وat وrequest_id وaction وrevision وfields وحالتيbefore/after عند توفرهما. يخدم حقل request_id ربط العملية بسجل HTTP المحمي عند التحقيق، ولا يمثل رمز صلاحية.

## التشغيل والتحقق

لا تحتاج السجلات القديمة إلى ترحيل؛ يظهر تاريخها فارغًا وتبدأ الكتابة مع العملية المدعومة التالية. تشمل نسخة قاعدة البيانات المشفرة هذه الحقول لأنها جزء من الوثائق، لكن فحص النسخة لا يغني عن سياسة احتفاظ خارجية إن كان المطلوب تاريخًا كاملًا.

اختبارات الميزة تستعمل MongoDB مؤقتة وحسابات مصطنعة، وتغطي الصلاحيات والإخفاء والتعارض وفشل التخزين والإدخال المزور وتاريخ الشركة والمالك والربط والحد100 وتغيّر اسم المنفّذ وحذفه والتحقق من الرد وتغيير الجلسة والإلغاء. معاينة المتصفح تستخدم المكوّن الحقيقي ببيانات مصطنعة دون تجديد جلسة مدير أو تغيير حالات حسابات وشركات التشغيل. ينبغي عدم اعتبار هذه المعاينة سجل تغييرات فعلية لقاعدة المنصة.
