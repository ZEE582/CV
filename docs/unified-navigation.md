# التنقل الرئيسي وحماية صفحات المنصة

22 نوفمبر 2026 — يحل هذا التصميم محل قائمة «كل الصفحات» السابقة.

## تنظيم التنقل

شريط واحد خارج Suspense في App.tsx، بروابط الرئيسية والوظائف والشركات والسيرة الذاتية والتدريب والمساعد الذكي. تعرض حسابات المدير رابط الإدارة، وحسابات الشركات رابط لوحة الشركة. تفتح قائمة الحساب الملف الشخصي وتقديمات الباحث والدعم وتسجيل الخروج.

لا توجد قائمة تجمع الواجهات الثانوية في الناف بار. استكمال البيانات وتفاصيل الحساب داخل الملف الشخصي، وتفاصيل المسائل ومحرر الأكواد داخل التدريب، وصفحات الإدارة في قائمتها الجانبية، وتفاصيل الشركات من قوائم الشركات. يبقى /pages دليلًا قديمًا محميًا وغير مرتبط بالناف بار.

على الهاتف تفتح قائمة مختصرة بالأقسام الرئيسية نفسها. تغلق القوائم عند الانتقال أو النقر خارجها، ويعيد Escape التركيز إلى الزر. الشريط يميز القسم الحالي ويحافظ على حراس المسودات الحاليين. لا يُنهى الحساب إلا بعد وصول الانتقال إلى /logout.

## تسجيل الدخول

يفتح جذر الموقع / الصفحة الرئيسية /home للزائر دون تسجيل دخول. يشير شعار المنصة إلى الرئيسية سواء كان الزائر مسجلًا أم لا. يجمع مسار بلا عنوان بقية صفحات المنصة تحت RequireAuth وOutlet، بما فيها الدعم والدليل والمسارات المتغيرة وصفحة 404. ينتظر انتهاء استعادة الجلسة قبل عرض أي صفحة محمية، ويوجه الزائر إلى /login مع الاحتفاظ بالمسار والاستعلام والجزء المطلوب للعودة بعد الدخول.

إضافة إلى الرئيسية، تتاح للزائر /login و/signup و/verify-email و/forgot-password و/reset-password، حتى يمكن إنشاء الحساب وتأكيده واستعادته. يظهر للزائر شعار المنصة وروابط الدخول وإنشاء الحساب فقط. تمرر روابط المصادقة في الناف بار الوجهة المطلوبة، كما يفعل نموذج الدخول.

تبقى قيود الأدوار داخل الحد المشترك: تقديماتي للباحث، والإدارة للمدير أو الشركة مع القيود الداخلية الحالية. لم تُنشأ جلسة أو حساب أو صلاحية بديلة. يعتمد قبول الجلسة عند الاستعادة على /auth/me الحالي، وليس على بيانات حساب مخزنة وحدها.

هذه حماية لمسارات تطبيق React. لم تتغير صلاحيات API أو إتاحة ملفات JavaScript والصور. معاينات local-preview بيانات وهمية للتطوير فقط، وتستبعد من بناء ونسخة التسليم.

## التحقق

تختبر platform-access-client.test.cjs شجرة المسارات والحارس الحقيقيين مع جلسات وهمية معزولة: رفض كل المسارات الداخلية للزائر وحفظ وجهة العودة، إتاحة صفحات المصادقة الخمس، عدم كشف المحتوى أثناء استعادة الجلسة، ودخول المستخدم وقيود الأدوار. تستبدل أجسام الصفحات والإشارة المرئية للتحويل فقط، دون اتصال بقاعدة أو إنشاء رموز.

في المتصفح يُختبر تحويل زائر من رابط وظائف مباشر إلى الدخول. يُختبر شكل الشريط وقائمة الحساب والتنقل على الهاتف من مكونه الحقيقي مع بيانات وهمية واضحة، دون تغيير جلسة حقيقية. تفاصيل نتائج آخر فحص موجودة في تقرير التسليم.
