# CV - Personal Portfolio Website

A modern, responsive portfolio website built with React, TypeScript, and Vite, featuring a clean design with Tailwind CSS.

## Features

- **React 19** with TypeScript
- **Vite** for fast development and building
- **Tailwind CSS v4** for styling
- **React Compiler** for optimized performance
- **Heroicons** for icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ZEE582/CV.git

# Navigate to the project directory
cd CV

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev
```

### Build

```bash
# Build for production
npm run build
```

### Lint

```bash
# Run ESLint
npm run lint
```
