# 🚀 Ttwar Platform

A modern interactive platform designed to help users explore career opportunities and develop their technical skills through a smooth and engaging user experience.

---

## ✨ Features

* 🎨 Modern UI built with TailwindCSS
* ⚡ Advanced animations powered by Framer Motion
* 🧠 Smooth and intuitive user experience
* 🧊 Glass UI design with blur and glow effects
* 🖱️ Interactive 3D cards (Tilt + Mouse tracking)
* 📱 Fully responsive design
* ✍️ Dynamic text animations with highlighting effects

---

## 🛠️ Tech Stack

* React
* Vite
* TailwindCSS
* Framer Motion

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ttwar-platform.git
```

### 2. Navigate into the project directory

```bash
cd ttwar-platform
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

---

## 🌐 Usage

After running the project, open your browser and go to:

```
http://localhost:5173
```

You will see the main interface with all animations and interactive components working.
